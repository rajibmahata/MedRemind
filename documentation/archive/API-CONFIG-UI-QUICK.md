## ?? Quick Fixes

### **Key Not Saving?**
- Check format (must start with `sk-`)
- Restart app
- Check device storage

### **Test Fails?**
- Verify key is correct
- Check internet
- Check OpenAI billing

### **Scanning Not Working?**
1. ? Key configured?
2. ? Test passes?
3. ? Camera permission?
4. ? Internet working?
