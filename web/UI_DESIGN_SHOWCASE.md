## ?? Color Palette

### Primary Gradients
```css

background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* Pink - Secondary Features */
background: linear-gradient(135deg, #f093fb 0%, #f5576c 100%);

/* Cyan - Stats & Info */
background: linear-gradient(135deg, #4facfe 0%, #00f2fe 100%);

/* Green - Success & CTA */
```

## ?? Design Specifications

### Typography
```css
/* Headers */
font-weight: 700;
line-height: 1.2;

/* Body */
font-weight: 400;
line-height: 1.5;

/* Captions */
font-weight: 600;
font-size: 0.875rem;
```

### Spacing
```css
/* Border Radius */
Small:  8px   (Cards, inputs)
Medium: 12px  (Feature cards)
Large:  16px  (Main sections)
XLarge: 24px  (Buttons, CTA)

/* Padding */
Compact: 16px
Standard: 24px
Large: 48px

/* Margins */
Section: 32px (mt-8)
Element: 16px (mb-4)
```

### Elevation
```css
/* MudBlazor Elevation */
Subtle:  2  (Inner cards)
Default: 4  (Feature cards)
Strong:  8  (Login form)
```

### Icons
```css
/* Sizes */
Small:  24px
Medium: 48px
Large:  80px (Feature circles)
XLarge: 120px (404 page)
```
